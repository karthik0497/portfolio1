# Karthik B - Portfolio

## 🚀 Overview
Welcome to my personal portfolio! This is a modern, responsive Single Page Application (SPA) designed to showcase my journey as a **Python Backend & Robotics Engineer**. 

It highlights my expertise in building scalable backend systems, industrial automation, and robotics software using **Python, ROS2, and IoT technologies**.

## 🛠 Tech Stack
- **Frontend:** [React](https://reactjs.org/) (Vite)
- **Styling:** [Tailwind CSS](https://tailwindcss.com/)
- **Animations:** Framer Motion, Aceternity UI
- **Icons:** Lucide React
- **Syntax Highlighting:** Prism.js (Python/Light Theme)
- **Deployment:** Vercel

## ✨ Key Features
- **Light Theme Design:** A clean, professional aesthetic with alternating section backgrounds.
- **Dual Resume Support:** Dedicated buttons for **Python Resume** and **Robotics Resume** with PDF preview.
- **Interactive Code Block:** A dynamic "About Me" section styled as a Python class.
- **Responsive Projects Grid:** Showcase of key projects with images and links.
- **Contact Selection:** LinkedIn integration and centralized contact details.

## 📦 Installation & Setup

1. **Clone the repository:**
   ```bash
   git clone https://github.com/karthik0497/portfolio1.git
   cd portfolio1
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Run the development server:**
   ```bash
   npm run dev
   ```

4. **Build for production:**
   ```bash
   npm run build
   ```
